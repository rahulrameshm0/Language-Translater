# Vaylo

Vaylo is the app’s display name. Three connected speech shapes suggest English, Spanish, and Malayalam, with an abstract V silhouette. The cobalt background fits the existing interface; white and aqua keep the mark legible at launcher sizes. This is a creative name choice, not a trademark availability claim.

## Asset

- `assets/icon.png`: square 1024 × 1024 launcher icon for Android and iOS, configured in `app.json`.
- Created using the built-in imagegen tool, then exported at the platform icon resolution.
- Existing project IDs, application identifiers, and authentication schemes are retained to preserve the deployed integrations.

## Final generation prompt

Use case: logo-brand. Create a polished production app launcher icon for Vaylo, a mobile translator for English, Spanish and Malayalam. One single 1024 by 1024 square image, opaque full-bleed cobalt blue background #184F9E. Center a bold distinctive abstract V made from three smoothly interlocking speech-bubble ribbons: two white shapes and one restrained bright aqua shape. Rounded geometry, confident negative space, flat vector-like precision, friendly and exceptionally legible at 48 pixels. Main mark contained in the central 60% of the canvas so Android adaptive icon cropping never touches it. No letters, no text, no globe, no flags, no gradients, no shadows, no 3D, no frame, no rounded outer corners baked into the square, no device mockup. Deliver only the square icon artwork.
