# LingoBridge branding

Name: LingoBridge. In-app heading: Translation studio. Tagline: Translate your world.

The new opaque square launcher asset is assets/lingobridge-icon.png, generated using the imagegen skill: overlapping white/mint speech cards, a Latin A and Chinese 文, connected by exchange arrows on cobalt. It is 1254×1254; Expo resizes it for native launcher assets. The old Vaylo icon remains as a historical asset.

Android/iOS bundle IDs, Expo project slug, auth URL scheme and the existing signing key remain unchanged so this APK can update existing installations. New app version 1.4.0, native build 6.
