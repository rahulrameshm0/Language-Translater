# Vaylo interface

The translation workspace is the main visual element: generous text sizes, native scripts, and two clearly labeled language columns. Left alignment keeps longer Malayalam and Spanish passages readable. A quiet masthead uses greetings in all three languages.

Palette: paper blue #F7FAFF, ink #153459, action blue #184F9E, selection blue #E4EEFF, slate #52647A, white #FFFFFF. Platform-native sans-serif fonts provide native-script fallback and respect system text scaling. Titles use 34/41, translation content 22/34, and body copy 16/25. The layout has a 620-point maximum width and 24-point side padding. Navigation is a simple three-tab strip; source and translation surfaces receive the strongest hierarchy.

No decorative gradients, stock imagery, or animation. Controls use distinct selected states, screen-reader labels, and minimum 48-point touch targets. Error copy offers the next action and retains input.
